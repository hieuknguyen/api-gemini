Hướng Dẫn Chi Tiết Toàn Bộ Tham Số API Docs v2.0

Bảng tra cứu đầy đủ kiểu dữ liệu, giá trị mặc định và cách sử dụng từng tham số gửi vào /webhook/antigravity-chat hoặc /v1/chat

1. HTTP Request Headers (Bắt buộc)
Tên Header Trạng thái Giá trị mẫu Ý nghĩa & Hướng dẫn sử dụng
Content-Type Bắt buộc application/json Định dạng nội dung gửi lên bắt buộc là JSON payload.
X-API-Key Bắt buộc sk-antigravity-... Khóa bí mật dùng để xác thực quyền truy cập API Gateway (hoặc gửi qua header Authorization: Bearer <key>).
2. Danh Sách Tham Số Body (JSON Payload)
Tham số Kiểu dữ liệu Mặc định Mô tả chi tiết & Ví dụ
prompt string null
Câu hỏi, lệnh hoặc chỉ dẫn trực tiếp cho AI.
Ví dụ: "Phân tích tài liệu này và tóm tắt thành 3 ý chính"
Ghi chú: Có thể bỏ qua nếu bạn đã gửi kèm toàn bộ tin nhắn trong mảng messages.
model string gemini-3.8-flash-tiered
Lựa chọn mô hình AI xử lý:
• gemini-4-argon: Suy luận nâng cao, coding & tác vụ phức tạp (chỉ đầu ra văn bản)
• gemini-3.8-flash-tiered: Siêu nhanh, thông minh, đa năng (mặc định)
• gemini-3.1-pro-high: Suy luận cực sâu, lập trình & phân tích phức tạp
• gemini-2.5-flash: Ổn định, tiết kiệm quota
• claude-sonnet-4-6: Phong cách viết văn bản chuyên nghiệp, mượt mà
• claude-opus-4-6-thinking: Claude Opus tư duy giải quyết vấn đề khó
• flux-image-generator: Tự động chuyển sang chế độ tạo ảnh nghệ thuật Flux.1
files Mới array[object] null
Đính kèm mọi loại tài liệu và tập tin: Ảnh (PNG, JPG...), PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV, Text, Audio (MP3, WAV...), Video (MP4...), Code...
Cấu trúc: [{"data": "data:application/pdf;base64,...", "filename": "bao_cao.pdf"}]
⚡ Cơ chế tự động thông minh: Với file AI đọc được trực tiếp (ảnh, PDF, audio, video) → hệ thống gửi nguyên bản qua inlineData. Với file văn phòng (Word, Excel, PowerPoint...) → backend tự động trích xuất toàn bộ văn bản và bảng biểu đưa vào ngữ cảnh cho AI phân tích!
image / images string | array null
Chuỗi Base64 ảnh hoặc Data URI:
Dùng image: "data:image/png;base64,..." cho 1 ảnh đơn lẻ.
Dùng images: ["base64_1...", "base64_2..."] khi muốn gửi cùng lúc nhiều ảnh.
messages array[object] null
Lịch sử hội thoại nhiều lượt (Stateless Architecture):
Máy chủ tuân thủ nguyên tắc không lưu trữ tin nhắn người dùng. Client tự lưu và gửi kèm toàn bộ mảng tin nhắn mỗi khi chat:
[
  {"role": "user", "content": "Tên tôi là Hiếu"},
  {"role": "assistant", "content": "Chào Hiếu! Tôi có thể giúp gì cho bạn?"},
  {"role": "user", "content": "Tên tôi là gì?"}
]
Mỗi message user cũng có thể chứa kèm "image" hoặc "files".
skill_id string (không bắt buộc)
Mã ID của Kỹ Năng muốn áp dụng cho AI.
AI sẽ tự động nạp vai trò, kiến thức chuyên sâu và chỉ dẫn hệ thống của skill đó.
Skill ID chỉ được cấp cho tài khoản sở hữu. Tài khoản khác không thể liệt kê hoặc sử dụng skill này.
custom_system_prompt string null Chỉ dẫn hệ thống (System Prompt) trực tiếp tùy biến cho lượt gọi này. Sẽ được kết hợp hoặc ghi đè phù hợp với skill đã chọn.
thinking boolean false
true: Bật chế độ suy luận chuyên sâu từng bước (Thinking Process).
false (Khuyến nghị): Tắt suy luận để AI phản hồi tức thì với tốc độ cao nhất.
web_search boolean true
true: Cho phép AI tự động tra cứu Google Search thời gian thực, tổng hợp số liệu mới nhất và kèm link nguồn.
false: Tắt tìm kiếm mạng, chỉ dùng kiến thức đã học của mô hình.
temperature float 0.7
Độ sáng tạo của câu trả lời (từ 0.0 đến 2.0):
• 0.0 - 0.2: Phân tích logic, lập trình, kiểm tra lỗi, tính toán chính xác
• 0.7 - 1.0: Viết lách, sáng tạo nội dung, marketing, hội thoại tự nhiên
max_tokens integer 4096 Giới hạn số token đầu ra tối đa của câu trả lời (từ 1024 đến 65536 tùy mô hình).
session_id string null Mã phiên trò chuyện do client tự định danh (ví dụ: "sess_abc123") để theo dõi và đối soát.

Code mẫu gọi API với skill riêng tư

Tài khoản sở hữu có thể gửi Skill ID của mình trong body. Các tài khoản khác không được phép truy cập skill.

🐍 Python (requests) 
import requests

url = "http://localhost:5678/webhook/antigravity-chat"
headers = {
    "Content-Type": "application/json",
    "X-API-Key": "sk-antigravity-..."  # Dùng API Key đã tạo trong tài khoản của bạn
}

# Gửi prompt kèm theo Skill ID đã copy từ Web UI
payload = {
    "prompt": "Viết bài chia sẻ về xu hướng AI trong năm 2026",
    "skill_id": "YOUR_PRIVATE_SKILL_ID",
    "thinking": False,             # Tắt thinking để tốc độ phản hồi nhanh hơn
    "web_search": True             # Cho phép tra cứu Google cập nhật số liệu mới
}

res = requests.post(url, json=payload, headers=headers)
data = res.json()

print("Kỹ năng đã kích hoạt:", data.get("skill_used"))
print("Mã Skill ID:", data.get("skill_id"))
print("Nội dung AI trả lời:\n", data.get("response"))

🧠 Code Mẫu Python Hội Thoại Đa Lượt (Stateless - Gửi Kèm Messages)

Máy chủ tuân thủ chuẩn Stateless (không lưu trữ tin nhắn trên server nhằm đảm bảo quyền riêng tư). Client lưu lịch sử vào file chat_history.json trên máy mình, đọc ra và gửi kèm trong mỗi request để AI nhớ ngữ cảnh:

import os
import json
import requests

URL = "http://localhost:5678/webhook/antigravity-chat"
HEADERS = {
    "Content-Type": "application/json",
    "X-API-Key": "sk-antigravity-..."  # Thay bằng API Key của bạn
}
HISTORY_FILE = "chat_history.json"

def load_history():
    """1. ĐỌC LỊCH SỬ TỪ FILE JSON RA"""
    if os.path.exists(HISTORY_FILE):
        try:
            with open(HISTORY_FILE, "r", encoding="utf-8") as f:
                return json.load(f)
        except Exception:
            return []
    return []

def save_history(messages):
    """2. LƯU LỊCH SỬ CẬP NHẬT VÀO FILE JSON"""
    with open(HISTORY_FILE, "w", encoding="utf-8") as f:
        json.dump(messages, f, ensure_ascii=False, indent=2)

def chat(user_message):
    # Bước 1: Lấy toàn bộ đoạn hội thoại cũ từ file JSON
    messages = load_history()

    # Bước 2: Thêm tin nhắn mới của người dùng vào danh sách
    messages.append({
        "role": "user",
        "content": user_message
    })

    # Bước 3: Gửi toàn bộ danh sách messages lên API Gateway
    payload = {
        "messages": messages,
        "model": "gemini-3.8-flash-tiered",
        "web_search": True
    }
    response = requests.post(URL, json=payload, headers=HEADERS).json()

    ai_reply = response.get("response", "")
    print("AI:", ai_reply)

    # Bước 4: Lưu câu trả lời của AI vào danh sách
    messages.append({
        "role": "assistant",
        "content": ai_reply
    })

    # Bước 5: Ghi đè file JSON để bảo lưu ngữ cảnh cho các lần trò chuyện sau
    save_history(messages)

# --- VÍ DỤ SỬ DỤNG ---
# Lần 1: Giới thiệu thông tin
chat("Tên tôi là Hiếu, tôi là lập trình viên backend.")

# Lần 2: Hỏi lại - AI sẽ đọc file JSON và nhớ chính xác bạn là ai!
chat("Tên tôi là gì và tôi làm nghề gì?")

Code Mẫu Python Phân Tích Hình Ảnh (Multimodal Vision)

import requests, base64

url = "http://localhost:5678/webhook/antigravity-chat"
headers = {"X-API-Key": "sk-antigravity-..."}

with open("sample.jpg", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode("utf-8")

data = {
    "prompt": "Bức ảnh này có nội dung gì?",
    "image": img_b64,
    "thinking": False
}

res = requests.post(url, json=data, headers=headers)
print("AI Trả lời:", res.json().get("response"))
